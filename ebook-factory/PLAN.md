# 🏭 แผนงาน: โรงงานสร้างอีบุ๊ก (Ebook Factory)

> ระบบอัตโนมัติ: **โยนหัวข้อเข้าไป → ได้ storyboard มาตรวจ → อนุมัติ → ได้สินค้าพร้อมขาย 2 เวอร์ชัน**
> (เวอร์ชันอ่านบนเว็บ + ไฟล์ส่งโรงพิมพ์)

---

## 1. เป้าหมาย

สร้าง "ทรัพย์สินดิจิทัล" เป็นซีรีส์หนังสือภาพสี อ่านง่าย มีตัวการ์ตูนประกอบ
ขายได้ทั้งแบบอีบุ๊กบนเว็บ และพิมพ์เป็นหนังสือจริง โดยมีระบบผลิตที่ทำซ้ำได้ทุกเล่ม

**ซีรีส์แรก: 3 เล่ม**

| เล่ม | ชื่อ (ร่าง) | แกนเรื่อง |
|------|------------|----------|
| 1 | **"Claude คือใคร?"** | AI ตัวนี้มีดียังไง / Claude vs Claude Cowork vs Claude Code ต่างกันยังไง เลือกใช้ตัวไหนเมื่อไหร่ |
| 2 | **"Claude Cowork ฉบับจับมือทำ"** | สมัคร → ติดตั้ง → ใช้งานจริง step-by-step มีภาพประกอบทุกขั้น + จุดเด่นที่ควรเอาไปใช้ |
| 3 | **"เขียนโค้ดง่ายเหมือนดีดนิ้ว ด้วย Claude Code"** | โค้ดคืออะไร ทำไมคนทั่วไปกลัว → Claude Code แก้ปัญหานี้ยังไง → ติดตั้ง/ใช้งานละเอียด, วิธีประหยัดโทเคน, จัดการไฟล์, ใช้บนมือถือ, เอาผลงานขึ้นเว็บ + **20 เทคนิค** (สร้างเกม สร้างหนัง สร้างระบบ ฯลฯ) |

**ทุกเล่มต้องมี (มาตรฐานซีรีส์):**
- ภาพสีทั้งเล่ม + ตัวการ์ตูนมาสคอตประจำซีรีส์
- กล่องข้อความ 4 แบบ: 💡 *น่ารู้* / ⚠️ *สำคัญมาก* / ⚖️ *เปรียบเทียบ* / 🎯 *ลองทำเลย*
- **ลิงก์ทรัพยากรฝังในเนื้อหา** — เวอร์ชันอีบุ๊กเป็นปุ่มกด, เวอร์ชันพิมพ์เป็น QR Code อัตโนมัติ
  พาไปดู: ตัวอย่างผลงานจริง / วิดีโอสอน / โปรแกรมแจก / สกิลให้ดาวน์โหลด

## 2. ภาพรวมสายพานการผลิต (Pipeline)

```
คุณโยน "หัวข้อ" เข้ามา
        │
        ▼
┌─────────────────────┐
│ ① STORYBOARD        │  ระบบร่าง: โครงเรื่อง, วิธีเล่า, บทต่อบท,
│    (หน้า HTML)      │  ตัวการ์ตูนที่ใช้, โทนสี, จุดวางกล่องข้อความ,
│                     │  จุดวาง QR/ลิงก์, ของแจกที่ต้องเตรียม
└─────────┬───────────┘
          │  คุณเปิดดูในเบราว์เซอร์ → คอมเมนต์/สั่งแก้ → อนุมัติ
          ▼
┌─────────────────────┐
│ ② เขียนเนื้อหาเต็ม   │  เนื้อหาทุกบท + ภาพประกอบ SVG + กล่องข้อความ
│    (Draft เต็มเล่ม)  │  เก็บเป็นไฟล์ Markdown + JSON ใน books/
└─────────┬───────────┘
          │  ตรวจอีกรอบ (หน้า HTML เหมือนอ่านหนังสือจริง) → อนุมัติ
          ▼
┌─────────────────────┐
│ ③ โรงงานผลิต 2 เวอร์ชัน │
├─────────────────────┤
│ 🌐 WEB EBOOK         │  อ่านบนเว็บ พลิกหน้ามีแอนิเมชัน มีสารบัญกดได้
│                     │  ล็อกดาวน์โหลด / บางเล่มอ่านฟรี / บางเล่มต้องล็อกอิน
│ 🖨️ PRINT PDF         │  ไฟล์ PDF พร้อมส่งโรงพิมพ์ (ขอบตัดตก, ฟอนต์ฝัง,
│                     │  QR Code แทนทุกลิงก์) ตรวจได้ทันทีจากเบราว์เซอร์
└─────────────────────┘
```

**หลักการสำคัญ:** เนื้อหาเก็บเป็น "ต้นฉบับกลาง" (Markdown + JSON) ชุดเดียว
แล้ว render ออก 2 ทาง — แก้เนื้อหาที่เดียว ได้ผลทั้งเว็บและเล่มพิมพ์เสมอ

## 3. ระบบลิงก์ + QR Code (หัวใจของ "ของแถมซ่อนในเล่ม")

ในต้นฉบับ ผู้เขียนแค่ระบุ `{{resource: game-demo-01}}` — โรงงานจัดการที่เหลือ:

- ทุก resource มี **short link ผ่านโดเมนของคุณ** เช่น `yourdomain.com/r/g01`
  - เวอร์ชันเว็บ → กลายเป็นปุ่มกดสวยๆ
  - เวอร์ชันพิมพ์ → กลายเป็น **QR Code** วางในกรอบอัตโนมัติ
- ปลายทางของ short link **แก้ทีหลังได้** โดยไม่ต้องพิมพ์หนังสือใหม่ (สำคัญมากสำหรับเล่มกระดาษ!)
- นับสถิติได้ว่าคนสแกน/กดอะไรเยอะ → รู้ว่าของแจกไหนดึงคนได้จริง

## 4. เว็บไซต์ขาย + ระบบล็อกอิน

- **หน้าแรก:** ชั้นหนังสือ (bookshelf) — บางเล่ม/บางบทเปิดอ่านฟรีเป็นตัวอย่าง
- **ระบบสมาชิก:** ล็อกอินด้วยอีเมล → สิทธิ์รายเล่ม (ซื้อเล่มไหน อ่านเล่มนั้น)
- **การกันดาวน์โหลด (พูดตรงๆ):** เว็บกัน 100% ไม่ได้ (แคปหน้าจอได้เสมอ) แต่กัน "ความสะดวก" ได้ผลจริง:
  - ไม่มีไฟล์ PDF ให้โหลดตรงๆ — เนื้อหาถูกส่งทีละหน้าเฉพาะคนมีสิทธิ์
  - ปิดคลิกขวา/ลากรูป, ใส่ลายน้ำอีเมลผู้อ่านจางๆ (กันเอาไปแชร์ต่อ)
  - ไฟล์ดาวน์โหลด (PDF/ของแจก) ปล่อยเฉพาะบัญชีที่คุณปลดล็อกเท่านั้น

## 5. เทคโนโลยีที่เลือก (และเหตุผล)

| ส่วน | เครื่องมือ | เหตุผล |
|------|-----------|--------|
| ต้นฉบับหนังสือ | Markdown + JSON book-spec | คนอ่านง่าย เครื่องอ่านง่าย แก้ไขผ่าน Claude Code ได้ตรงๆ |
| ภาพการ์ตูน/ประกอบ | SVG ต้นฉบับ (วาดเป็นโค้ด) | สีคมทุกขนาด ใช้ได้ทั้งจอและพิมพ์ 300dpi, แก้สี/ท่าทางได้ด้วยการสั่งแก้โค้ด |
| หน้า Storyboard | HTML ไฟล์เดียว เปิดได้เลย | ตรวจงานได้ทันทีไม่ต้องติดตั้งอะไร |
| Web reader | HTML/CSS/JS (แอนิเมชันพลิกหน้า) | เบา เร็ว ควบคุมการล็อกเนื้อหาได้เอง |
| ไฟล์พิมพ์ | HTML → PDF ด้วย **Paged.js + Playwright/Chromium** | ได้ PDF ขอบตัดตก (bleed) เลขหน้า สารบัญ ตรงตามที่เห็นในเบราว์เซอร์ 100% |
| QR Code | ไลบรารี `qrcode` สร้างเป็น SVG | ฝังในหน้าพิมพ์คมชัด |
| เว็บ+สมาชิก | Node.js + Express + SQLite | ทีมเดียวกับโปรเจกต์เดิมในรีโปนี้ ดูแลง่าย ย้ายขึ้นโฮสต์ถูกๆ ได้ |

## 6. โครงสร้างโฟลเดอร์ที่จะสร้าง

```
ebook-factory/
├── PLAN.md                  ← เอกสารนี้
├── factory/                 ← เครื่องจักรของโรงงาน
│   ├── storyboard/          ← สร้างหน้า storyboard จากหัวข้อ
│   ├── render-web/          ← ผลิตเวอร์ชันอ่านบนเว็บ
│   ├── render-print/        ← ผลิต PDF ส่งโรงพิมพ์ (Paged.js)
│   ├── links/               ← ระบบ short link + สร้าง QR
│   └── templates/           ← เลย์เอาต์หน้า, กล่องข้อความ 4 แบบ, ธีมสี
├── assets/
│   └── mascots/             ← ตัวการ์ตูนมาสคอต (SVG) ท่าทางต่างๆ
├── books/                   ← ต้นฉบับหนังสือทีละเล่ม
│   ├── 01-claude-intro/
│   ├── 02-claude-cowork/
│   └── 03-claude-code/
└── site/                    ← เว็บไซต์ขาย + reader + ล็อกอิน
```

## 7. ⚠️ เรื่องที่ต้องรู้ก่อนขาย: โลโก้แบรนด์จริง

การเอา **โลโก้จริงของ Anthropic/Claude** มาทำเป็นตัวการ์ตูนตกแต่ง *สินค้าที่ขาย*
มีความเสี่ยงเรื่องเครื่องหมายการค้า (แบรนด์ใหญ่ทุกเจ้ามีข้อห้ามแบบนี้ในไกด์ไลน์)

**ทางที่ปลอดภัยและได้ผลเหมือนกัน:**
1. ✅ ใช้ **ชื่อแบรนด์ในเนื้อหาได้ปกติ** (สอนการใช้ Claude, รีวิว, เปรียบเทียบ — ทำได้)
2. ✅ สร้าง **มาสคอตต้นฉบับของซีรีส์เราเอง** ที่ "ให้อารมณ์" ของแบรนด์ (เช่น เจ้าตัวกลมสีส้มอบอุ่นสไตล์ Claude) แต่ไม่ใช่การลอกโลโก้ — เป็นทรัพย์สินของเรา ใช้ขายได้ทุกเล่ม และกลายเป็นเอกลักษณ์ของแบรนด์หนังสือเราเอง
3. ✅ ใส่ข้อความ "หนังสือเล่มนี้ไม่ใช่สินค้าทางการของ Anthropic" ในหน้าลิขสิทธิ์
4. ❌ ไม่วางโลโก้จริงบนปก/ในเล่มแบบเป็นลายตกแต่ง

> แผนนี้จึงออกแบบ "ครอบครัวมาสคอต" ประจำซีรีส์: ตัวหลัก 1 ตัว + ตัวประกอบ
> ที่เปลี่ยนชุด/อุปกรณ์ตามหัวข้อแต่ละเล่ม (เล่มโค้ดถือแล็ปท็อป, เล่ม Cowork ใส่หูฟัง ฯลฯ)

## 8. แผนลงมือทำ (เป็นเฟส เห็นของจริงทุกเฟส)

### เฟส 1 — โครงโรงงาน + Storyboard เล่มแรก
- โครงสร้างโฟลเดอร์, รูปแบบ book-spec, ธีมสี, กล่องข้อความ 4 แบบ
- ออกแบบมาสคอต SVG ตัวแรก (หลายท่าทาง)
- สร้างหน้า Storyboard เล่ม 1 ให้คุณตรวจ → **ได้เห็นหน้าตรวจงานจริงครั้งแรก**

### เฟส 2 — เครื่องผลิต 2 เวอร์ชัน
- Web reader: พลิกหน้ามีแอนิเมชัน, สารบัญกดได้, โหมดตัวอย่างฟรี
- Print pipeline: HTML → PDF พร้อมพิมพ์ (bleed, เลขหน้า, QR)
- ระบบ short link + QR → **โยนต้นฉบับเข้า ได้ไฟล์ออก 2 แบบจริง**

### เฟส 3 — เว็บไซต์ขาย + สมาชิก
- หน้าชั้นหนังสือ, ล็อกอิน, สิทธิ์รายเล่ม, ปลดล็อกดาวน์โหลด, ลายน้ำ

### เฟส 4 — ผลิตจริง 3 เล่มแรก
- เขียนเนื้อหาเต็ม เล่ม 1 → 2 → 3 ผ่านสายพาน storyboard → ตรวจ → ผลิต
- เตรียม "ของแจก" ประกอบเล่ม (สกิล, เทมเพลต, วิดีโอ) + landing page ของแต่ละ QR

## 9. สิ่งที่ต้องตัดสินใจ (ตอบเมื่อไหร่ก็ได้ ไม่บล็อกเฟส 1–2)

1. **ขนาดเล่มพิมพ์:** แนะนำ A5 (พกง่าย ต้นทุนถูก) หรือ B5 (ภาพใหญ่ อ่านสบาย) — เดี๋ยวทำ layout รองรับที่เลือก
2. **โดเมน** สำหรับเว็บและ short link (มีอยู่แล้วหรือต้องจดใหม่?)
3. **ช่องทางรับเงิน:** Stripe / PromptPay / ขายผ่านแพลตฟอร์ม (meb, Ookbee) ควบคู่?
4. **โฮสติ้ง:** แนะนำเริ่มที่ VPS ถูกๆ หรือ Railway/Render (~$5/เดือน) พออยู่ได้ทั้งเว็บ+สมาชิก
