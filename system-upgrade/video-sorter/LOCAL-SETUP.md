# 💻 วิธีให้ Claude ทำงาน "ในเครื่อง Mac" ของโค้ช
> ตอบคำถามโค้ช 1 ก.ค. 2026: "คุณอยู่บนคลาวด์ คุณต้องทำในเครื่องผมได้เลยสิ"

## ทำไมห้องแชทนี้แตะเครื่อง Mac ไม่ได้

ห้องที่โค้ชเปิดจากมือถือ/เว็บ = Claude Code **บนคลาวด์** ตัวผมรันอยู่ในกล่องปิดของ Anthropic
ที่เห็นได้แค่รีโพ GitHub นี้เท่านั้น — **ถูกออกแบบมาให้ขอเจาะเข้าเครื่องใครไม่ได้เลย**
(เป็นเรื่องความปลอดภัย: ถ้าห้องคลาวด์ขอ access เครื่องคนได้ คนร้ายก็ทำได้เหมือนกัน)

**ทางที่ถูกต้องคือกลับด้าน: ไปเปิด Claude Code บนเครื่อง Mac** — ตัวที่รันในเครื่อง
เห็นไฟล์ทุกไฟล์ รันสคริปต์ได้ อัป FTP ได้ ครบทุกอย่างที่โค้ชอยากให้ทำ
(เข้าใจว่าโค้ชมีอยู่แล้ว เพราะเพิ่งโหลดปลั๊กอิน 5 ตัว — ทีมฮีโร่ทั้งหมดก็รันแบบนี้)

## ขั้นตอน (ทำครั้งเดียว ~3 นาที)

1. เปิด **Terminal** บน Mac (หรือแอป Claude Code)
2. ดึงรีโพนี้ลงเครื่อง (ถ้ามีแล้วข้ามไป `git pull`):
   ```bash
   git clone https://github.com/kikbekery-source/ubiquitous-garbanzo.git
   cd ubiquitous-garbanzo
   git checkout claude/backend-system-review-2e2wlb
   ```
3. ติดตั้ง ffmpeg ถ้ายังไม่มี (ใช้ดึงภาพจากคลิป):
   ```bash
   brew install ffmpeg
   ```
4. เปิด Claude ในโฟลเดอร์นี้:
   ```bash
   claude
   ```
5. **คัดลอกข้อความข้างล่างนี้วางลงไปทั้งก้อน** แล้วปล่อยให้ Claude ในเครื่องทำต่อ:

```
อ่าน system-upgrade/video-sorter/LOCAL-SETUP.md และ MODES.md แล้วทำงานเป็นกาโมร่า ตามนี้:

1. ถามผมก่อนว่าโฟลเดอร์ฟุตเทจดิบอยู่ที่ไหน และจะให้ตั้งคลังคลิปไว้ที่ไหน
2. คัดแยกของเก่าทั้งหมดด้วยโหมด 2 (ภาพนิ่ง):
   - รัน system-upgrade/video-sorter/extract_frames.sh กับโฟลเดอร์ฟุตเทจ
   - เปิดดูเฟรมของแต่ละคลิปด้วยตาตัวเอง แล้วสร้าง plan.json
     (ฟิลด์: file, cat=PROD/PREP/TALK/OTH, title, confidence, note)
   - รัน python3 system-upgrade/video-sorter/footage_tool.py apply
     --library <คลัง> --plan plan.json
   - เปิด INDEX.md ให้ผมดูสรุป และชี้คลิปที่ติดธง ⚠️ ให้ผมเช็คเอง
3. ติดตั้ง "ลงทะเบียนตั้งแต่ตอนสร้าง" เข้าโรงงานผลิต:
   หา pipeline สร้างคลิปในเครื่อง (auto_content.py, build_episode.py ฯลฯ)
   แล้วเพิ่มขั้นตอนสุดท้ายให้เรียก footage_tool.py register
   พร้อมหมวด+ชื่อเรื่องที่ pipeline รู้อยู่แล้ว — ต่อไปคลิปใหม่เข้าสารบัญเองทุกตัว
4. อัปโฟลเดอร์ system-upgrade ขึ้นเซิร์ฟเวอร์ตาม system-upgrade/README.md
   (login /system/ + แจ้งเตือน + คอมเมนต์ปักหมุด) แล้วเทสต์ผ่านเบราว์เซอร์จริง
5. เสร็จแต่ละข้อ รายงานเข้า rooms-api ตาม standards/APPROVAL-STANDARD.md ข้อ 4
```

## หลักการที่โค้ชเคาะแล้ว (1 ก.ค. 2026)

- **คลิปที่เราสร้างเอง → ลงทะเบียนตอนสร้างเลย ไม่ต้องให้ AI เดาย้อนหลัง**
  โรงงานผลิตรู้อยู่แล้วว่ากำลังเรนเดอร์เมนูอะไรฉากแบบไหน แค่บันทึกลงทะเบียน ณ วินาทีที่เรนเดอร์เสร็จ
  (แม่น 100% ฟรี 100%) — `footage_tool.py register` มีไว้เพื่อสิ่งนี้
- **AI คัดแยก (โหมด 2 ภาพนิ่ง) ใช้กับของเก่าค้างสต็อกเท่านั้น** — ล้างสต็อกจบครั้งเดียวแล้วไม่ต้องใช้อีก
- ทุกทางลงทะเบียนจบที่เดียวกัน: โฟลเดอร์หมวดหมู่ + รหัสนำหน้า + `INDEX.md` สารบัญ

## แบ่งงานคลาวด์ vs เครื่อง

| งาน | ทำที่ไหน |
|---|---|
| เขียน/แก้โค้ด, ตรวจระบบ, เอกสาร, PR | ☁️ ห้องคลาวด์ (ห้องนี้) |
| ไฟล์วิดีโอ, รันคัดแยก, อัป FTP, QA รันวนออโต้ | 💻 Claude Code ในเครื่อง Mac |

สองฝั่งเจอกันที่รีโพ GitHub + ระบบห้องงาน (rooms.json) — ผมอัปเดตฝั่งโค้ด ฮีโร่ในเครื่องอัปเดตฝั่งเครื่อง โค้ชเห็นรวมที่ /system/ ที่เดียว
